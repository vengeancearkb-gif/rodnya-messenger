# 📱 Семейный Мессенджер «Родня»

Сверхбыстрый, легковесный мессенджер с поддержкой **текста**, **голосовых сообщений**, **фото/файлов** и **аудиозвонков (WebRTC)**, специально оптимизированный для стабильной связи с родственниками в других странах.

---

## ✨ Основные возможности

| Функция | Описание |
|---|---|
| 💬 **Быстрый чат** | Мгновенная доставка сообщений через WebSockets с минимальным пингом. |
| 🎙️ **Голосовые сообщения** | Запись голоса в формате Opus/WebM, таймер записи и удобный встроенный плеер. |
| 📞 **Аудиозвонки (HD)** | Прямые голосовые звонки через WebRTC (Google STUN) — отличное качество даже на медленном 3G/4G. |
| 📷 **Фото и файлы** | Отправка фотографий с просмотром на весь экран и любых документов до 50 МБ. |
| 🌍 **Стабильность за рубежом** | Защищенный трафик (WSS/HTTPS на порту 443), автопереподключение за 1 секунду при смене сетей. |
| 🔒 **Простой вход без SMS** | Достаточно ввести имя и общий семейный код комнаты (например, `semya` или `rodnya2026`). Никаких блокировок международных SMS! |

---

## 🚀 Быстрый старт на компьютере

Чтобы протестировать мессенджер прямо сейчас в браузере:

```bash
./start.sh
```
Затем откройте в браузере: **`http://localhost:3000`**
> 💡 *Совет: откройте две вкладки (или одну в режиме инкогнито), введите разные имена (например, «Мама» и «Сын») и один код комнаты. Вы сразу сможете переписываться, отправлять голосовые и звонить!*

## 📲 Установка APK на Android

Готовый установочный файл приложения:
👉 **`release/Rodnya-Messenger.apk`**

### Как перенести и установить на смартфон:
1. Отправьте файл `Rodnya-Messenger.apk` на телефон (через Telegram «Избранное», Google Диск, кабель USB или скачайте напрямую по локальной сети).
2. На телефоне откройте APK и нажмите **«Установить»** (если система спросит разрешение на установку из неизвестных источников — подтвердите).
3. При первом запуске разрешите доступ к **микрофону** (нужно для звонков и голосовых) и **памяти/камере** (для отправки фото).

## ☁️ Бесплатный запуск сервера для связи между странами

Чтобы мессенджер работал из любой точки мира без покупки дорогих серверов:

### Инструкция по бесплатному деплою на Render.com (2 минуты):
1. Зарегистрируйтесь на [Render.com](https://render.com) (бесплатно).
2. Загрузите файлы репозитория на GitHub (публичный или приватный репозиторий).
3. На Render нажмите **New +** → **Web Service** и выберите ваш репозиторий.
4. Настройки:
   - **Root Directory:** `server`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** `Free`
5. Нажмите **Deploy**.
6. Через минуту Render предоставит постоянный защищенный адрес, например:
   `https://my-family-messenger.onrender.com`
7. В мобильном приложении нажмите на значок **⚙️ (Настройки)** и в поле **«Адрес сервера»** вставьте эту ссылку.
8. Всё! Теперь вы и ваши родственники за рубежом всегда на связи!

## 🛠️ Сборка APK из исходников

Если вы измените дизайн или добавите новые функции, пересобрать APK можно одной командой:

```bash
./build_apk.sh
```
Скрипт автоматически синхронизирует изменения и скомпилирует свежий APK в папку `release/`.
