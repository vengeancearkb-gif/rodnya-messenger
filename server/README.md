# 🚀 Сервер семейного мессенджера «Родня»

Легковесный и сверхбыстрый бэкенд для обмена сообщениями, голосовыми записями, файлами и аудиозвонками между разными странами.

---

## ⚡ Особенности для международной связи
1. **Работа через HTTPS / WSS (порт 443):** Трафик маскируется под обычный защищенный веб-серфинг, что защищает от блокировок провайдерами, DPI и ограничений скорости.
2. **Агрессивный Heartbeat (Ping-Pong 10 сек):** Моментально определяет разрыв мобильного интернета и восстанавливает связь без потери сообщений.
3. **WebRTC STUN / HD Audio (Opus):** Кристально чистый звук в аудиозвонках при минимальном расходе трафика (отлично работает даже на медленном 3G).
4. **Хранение истории сообщений:** Когда родственник заходит в сеть, он сразу видит все последние сообщения в комнате.

---

## ☁️ Бесплатный запуск в облаке (за 2 минуты)

Чтобы родственники в другой стране могли подключиться к вашему мессенджеру, сервер должен быть доступен в интернете. Самый простой и 100% бесплатный способ — **Render.com**:

### Вариант 1: Развертывание на Render.com (Бесплатно)
1. Зарегистрируйтесь на сайте [Render.com](https://render.com) (можно войти через Google или GitHub).
2. Создайте репозиторий на [GitHub](https://github.com) и загрузите туда файлы проекта (или папку `server`).
3. В панели Render нажмите **New +** → **Web Service**.
4. Подключите ваш GitHub-репозиторий.
5. Заполните поля:
   - **Root Directory:** `server` (если репозиторий со всем проектом) или оставьте пустым (если загрузили только папку server).
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Plan:** `Free`
6. Нажмите **Deploy Web Service**.
7. Через минуту вы получите постоянный защищенный адрес вида:
   `https://family-messenger-xxxx.onrender.com`
8. Этот адрес вы и ваши родственники вводите в настройках приложения в поле **Адрес сервера**!

---

### Вариант 2: Локальный запуск на компьютере
```bash
cd server
npm install
node server.js
```
Сервер будет доступен по адресу: `http://localhost:3000`

## 📁 Структура API
- `GET /api/health` — проверка работоспособности сервера
- `POST /api/upload` — загрузка фото, голосовых и файлов
- `GET /uploads/:filename` — скачивание загруженных медиа
- `WebSocket (Socket.IO)` — обмен сообщениями в реальном времени, индикатор набора текста и сигналы для WebRTC звонков.
