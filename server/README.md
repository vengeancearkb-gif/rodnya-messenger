# 🚀 Сервер семейного мессенджера «Родня»

Легковесный и сверхбыстрый бэкенд для обмена сообщениями, голосовыми записями, файлами и аудиозвонками между разными странами.

---

## ⚡ Особенности для международной связи
1. **Защищенный протокол HTTPS / WSS (порт 443):** Трафик шифруется, защищая от перехвата и блокировок провайдерами.
2. **Мобильный Heartbeat (Ping 25 сек, Timeout 20 сек):** Предотвращает ложные обрывы на мобильном интернете 3G/4G/5G.
3. **WebRTC STUN / HD Audio (Opus):** Прямая P2P связь без задержек с кристально чистым звуком.
4. **Надежная аутентификация и профили:** Хэширование паролей с помощью PBKDF2 (100 000 итераций SHA-512) и привязка устройств через безопасные Device Secrets. Никаких паролей в открытом виде!
5. **Безопасная загрузка файлов:** Ограничение 50 МБ, белый список безопасных расширений, защита от Stored XSS (`X-Content-Type-Options: nosniff` и CSP).
6. **Автономное самовосстановление:** Автоматическое восстановление сессии при перезапуске облачного контейнера.

## ☁️ Развертывание на Render.com (Бесплатно)

1. Зарегистрируйтесь на сайте [Render.com](https://render.com).
2. Подключите ваш GitHub-репозиторий `rodnya-messenger`.
3. В панели Render создайте **Web Service**:
   - **Root Directory:** оставьте пустым или укажите `server`.
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server/server.js` (если root пустой) или `node server.js` (если root `server`).
   - **Plan:** `Free`
4. Нажмите **Deploy Web Service**.
5. Постоянный защищенный адрес сервиса: `https://rodnya-messenger.onrender.com`

## 📁 Документация API

### Аутентификация и профили
- `POST /api/auth/register` — регистрация профиля (логин, пароль, имя, аватар, статус)
  - Тело запроса: `{ "username": "alex", "password": "...", "displayName": "Алексей", "avatar": "...", "bio": "..." }`
  - Ответ: `{ "ok": true, "token": "...", "deviceSecret": "...", "user": { ... } }`
- `POST /api/auth/login` — вход по логину и паролю
  - Тело запроса: `{ "username": "alex", "password": "..." }`
  - Ответ: `{ "ok": true, "token": "...", "deviceSecret": "...", "user": { ... } }`
- `GET /api/auth/me` — получение данных текущего авторизованного пользователя
  - Заголовок: `Authorization: Bearer <token>`
- `POST /api/auth/restore-session` — безопасное восстановление сессии устройства
  - Тело запроса: `{ "username": "alex", "deviceSecret": "...", "displayName": "...", "avatar": "...", "bio": "..." }`
- `POST /api/profile/update` — обновление имени, аватара и статуса
  - Заголовок: `Authorization: Bearer <token>`
  - Тело запроса: `{ "displayName": "...", "avatar": "...", "bio": "..." }`
- `GET /api/profile/:username` — публичный профиль участника (имя, статус, аватар, статус «в сети / занят»)

### Файлы и медиа
- `POST /api/upload` — загрузка фото, голосовых и документов (до 50 МБ)
  - Заголовок: `Authorization: Bearer <token>`
  - Формат: `multipart/form-data`, поле `file`
- `GET /uploads/:filename` — безопасное скачивание/просмотр загруженных медиафайлов
- `GET /api/health` — мониторинг работоспособности сервера и количества пользователей

### WebSocket события (Socket.IO)
- `join-room` — подключение к семейной комнате с проверкой токена / deviceSecret
- `send-message` — отправка текстовых, голосовых и файловых сообщений
- `typing` — индикатор набора текста
- `call-user`, `call-answer`, `call-reject`, `call-end`, `ice-candidate` — WebRTC-сигнализация для звонков с проверкой комнаты и защитой от вызова занятого абонента
